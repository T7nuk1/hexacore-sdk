# hexacore-sdk — документация

SDK для платы на микроконтроллере **MIK32 Амур** (RISC-V rv32imc, 32 МГц):
драйверы периферии платы, сборка через CMake, два режима — bare metal и FreeRTOS.

Компилятор, прошивальщик, сам SDK и примеры ставит расширение — отдельно
настраивать окружение не нужно.

## С чего начать

Читать по порядку. В конце каждого раздела есть задания с чекбоксами,
разбитые на три уровня: **повторить** (собрать и прошить как есть),
**изменить** (поменять параметр и объяснить результат) и **сделать своё**
(открытая задача). Отмечать выполненное можно прямо в файле.

| Документ | О чём |
|---|---|
| [01-quickstart.md](01-quickstart.md) | Первая сборка и прошивка, отладочный вывод |
| [02-project.md](02-project.md) | Свой проект с нуля: `app_main`, CMakeLists, что даёт `sdk_add_executable` |
| [03-modes.md](03-modes.md) | bare metal против FreeRTOS: что делает BSP, что делает приложение |

Особняком стоит `examples/demo` — прошивка, задействующая весь SDK разом:
пять экранов с показаниями всех датчиков, кнопки, пищалка, вся геометрия
дисплея. Её удобно заливать первой на новую плату, чтобы разом увидеть, что
из железа отвечает, а что нет.

## Состав репозитория

```
board/      hexa_board.h/.c — раскладка платы, адреса, hexa_board_init()
drivers/    include/*.h — публичный API, src/*.c — реализация
bsp/        main() для bare metal и для FreeRTOS
cmake/      тулчейн, sdk.cmake, шаблоны новых проектов
examples/   рабочие примеры, по одному на подсистему, плюс demo — всё сразу
hal/        вендорный HAL MIK32
shared/     вендорные библиотеки (в т.ч. xprintf), ldscripts, crt0
freertos/   ядро FreeRTOS
uploader/   прошивальщик, его вызывает расширение
```

Документируются только `board/`, `drivers/`, `bsp/`, `cmake/` и `examples/` —
всё остальное вендорское и живёт своей жизнью.

## Драйверы

| Заголовок | Устройство | Шина |
|---|---|---|
| `hexa_types.h` | `hexa_status_t`, `hexa_pin_t` | — |
| `hexa_time.h` | задержки, единые для обоих режимов | — |
| `hexa_uart.h` | отладочный UART, 9600 8N1 | UART_0 |
| `hexa_i2c.h` | шина I2C (мастер) | I2C_1 |
| `hexa_button.h` | кнопки платы | GPIO |
| `hexa_buzzer.h` | пищалка на ШИМ | TIMER32_1 |
| `hexa_oled.h` | OLED SSD1306 128×64 | I2C 0x3C |
| `hexa_mpu.h` | MPU6050, акселерометр + гироскоп | I2C 0x68 |
| `hexa_rv3032.h` | RV-3032-C7, часы реального времени | I2C 0x51 |
| `hexa_vl53l0x.h` | VL53L0X, лазерный дальномер | I2C 0x29 |
| `hexa_aht20.h` | AHT20, температура и влажность | I2C 0x38 |
| `hexa_bmp280.h` | BMP280, давление и температура | I2C 0x76 |

Чего в SDK **нет**: драйверов SPI, ADC и внутреннего RTC MIK32. Всё это доступно
только напрямую через вендорный HAL.

## Правила чтения

Заголовки в `drivers/include/` — основной источник правды: в них описана
семантика каждой функции. Эта документация объясняет, как части складываются
вместе, но не заменяет заголовок.
