Для работы расширения с платами MIK32 ELBEAR для начала необходимо установить необходимые зависимости, а так же настроить программатор ELJTAG

**Дополнительные зависимости**
Для сборки и работы проекта в вашей системе должны быть установлены Python (версии 3.8 или выше) и CMake.

- Python 3.8+ ([https://www.python.org/downloads/](https://www.python.org/downloads/))
- CMake (https://cmake.org/download/)

Вы можете скачать их с официальных сайтов или воспользоваться пакетным менеджером вашей операционной системы. Убедитесь, что оба инструмента добавлены в системную переменную окружения `PATH`.

**Установка зависимостей**
Для корректной работы с расширением необходимо установить необходимые зависимости.
Порядок действий:
1. Перейти на главную страницу расширения HexaCore
2. Начать загрузку зависимостей, нажав на кнопку  в меню "Установить sdk".
3. Дождаться завершения установки, статус которой отображается в правом нижнем углу VS Code. 
![alt text](<Pastedimage20260718132342.png>)

При успешной установки в меню станут доступны все функции, а в статусе установки появится сообщение "Hexacore SDK успешно установлен" . 
![alt text](<Pastedimage20260718133622.png>)

**Настройка программатора** 
Для корректной работы программатора ELJTAG необходимо установить подходящие драйвера.
Последовательность действий: 
1. Перейти по пути C:/Users/%User%/.hexacore-dependencies (Windows)
2. Подключить ELJTAG к ПК. 
3. Запустить программу Zadig, находящуюся в папке .hexacore-dependencies.![alt text](<Pastedimage20260718134655.png>)
4. Во вкладке Option выбрать опцию List All Devices. После этого в выпадающем списке на главном окне должны определяться некоторые устройства.![alt text](<Pastedimage20260718134726.png>)
5. В выпадающем списке выбрать "Dual RS232-HS (Interface 0)". 
6. В строке Driver в окне 1 (см рисунок) выбрать "libusb-win32", нажимая на кнопки со стрелками. 
7. Нажать кнопку "Replace Driver" и подождать завершения установки. 
8. В выпадающем окне выбрать устройство "Dual RS232-HS (Interface 1)". 
9. Повторить пункты 4...5. 
10. После установки драйверов необходимо отключить устройство и подключить заново для начала работы.


**Создание проекта**
Для создания проекта:
1. Перейти на главное меню расширения.
2. В главном меню расширения выбрать "Создание нового проекта".![alt text](<Pastedimage20260718145844.png>)
3. В окне создания проекта выбрать название и путь рабочей папки. В качестве первого запуска рекомендуем выбрать проект "Светодиод", чтобы нагляднее убедится в корректности установки расширения. Убедившись в правильности выбранного пути выберите "Создать".![alt text](<Pastedimage20260718151632.png>)
4. После создания папки проекта вы будете перенаправлены в новое окно с открытым проектом, в котором находятся два файла: blink.c и CMakeLists.txt.
5. Подключите плату по ELJTAG к ПК.
6.  Откройте файл blink.c. В нижней панели инструментов выберите "Прошить" после чего откроется новый терминал с информацией о сборке и прошивке.![alt text](<Pastedimage20260718172901.png>)
7. Если в терминале не возникло никаких ошибок, а светодиод на плате начал мигать, то все зависимости установлены верно и вы можете свободно пользоваться расширением.
